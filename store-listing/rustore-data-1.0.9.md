# Проверка декларации данных RuStore для 1.0.9

Сверено с кодом выпуска и действующей политикой приложения. Это описание уже существующих функций; состав разрешений APK совпадает с 1.0.8 (23), новых разрешений нет.

| Категория | Основание в проекте |
| --- | --- |
| Точное и приблизительное местоположение | `src/location/driver-background-location.ts`, `src/legal/content.ts`: место подачи и положение водителя на линии/в поездке |
| Номер телефона, имя, ID пользователей | `src/domain/models.ts` SessionUser; `server/routes.ts`: авторизация и профиль |
| Адрес | `src/legal/content.ts`: адреса подачи и назначения, история поездок |
| Другие личные данные | `src/domain/models.ts`: пол; `server/routes.ts`: водительское удостоверение и автомобиль |
| ID устройства или другие идентификаторы | `server/auth-abuse.ts`: обезличенный installationFingerprint; идентификаторы сессии и push-регистрации |
| Фотографии | `src/screens/ride/ride-chat-screen.tsx` и `profile-screen.tsx`: выбор только `mediaTypes: ['images']`; `server/ride-chat.ts`: проверка JPEG, PNG, WebP |
| Другие сообщения в приложениях | `server/ride-chat.ts`: текст чата пассажира и водителя |
| Другой пользовательский контент | `src/domain/models.ts`: комментарии и оценки поездок |
| Взаимодействие с приложением | `src/legal/content.ts`: заказы, статусы, история, согласия и административные действия |
| История покупок | `src/domain/models.ts`: история поездок, стоимость и выбранный способ оплаты |
| Другие финансовые данные | `src/domain/models.ts`: выручка, комиссия и доход водителя |
| Диагностика | `src/legal/content.ts`: IP, User-Agent, журналы безопасности и диагностики |

Видео, пользовательские аудиофайлы и произвольные документы не принимаются: UI выбирает только изображения, а сервер проверяет их MIME и сигнатуру. `microphonePermission: false` указан в `app.json`. Предзаполненные RuStore категории из широких разрешений библиотеки выбора медиа не соответствуют фактическому сбору этих данных.

## Обоснование разрешений

Точное и приблизительное местоположение нужны для выбора места подачи и отображения машины. Фоновое местоположение используется только у водителя на линии или в поездке, после отдельного пояснения и разрешения. Камера и доступ к хранилищу нужны для фотографий в чате и аватара по действию пользователя; приложение принимает только изображения. POST_NOTIFICATIONS используется для статусов заказа и сообщений. Запись звука и сбор видео не выполняются.
