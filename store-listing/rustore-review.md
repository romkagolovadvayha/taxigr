# Доступ для модерации RuStore

Версия: **1.0.11**.

Добавлены уведомление об обновлении один раз на новую версию и кнопка обновления в профиле с переходом в магазин установки. Окно не мешает активным поездкам.

- Тестовый пассажир: `+7 999 888-77-66`.
- Постоянный код подтверждения: `4455`.

1. Нажмите «Войти по SMS» под кнопками мессенджеров.
2. Нажмите «Принять и продолжить».
3. В поле номера введите `9998887766`: код страны `+7` уже указан.
4. Нажмите «Получить код по SMS».
5. Введите `4455` и нажмите «Подтвердить код».

SMS и внешние аккаунты VK, MAX или Telegram для этого номера не нужны.
Аккаунт имеет роль пассажира. Для входа не нужны оплата или подписка.
Можно выбрать адреса, рассчитать стоимость и просмотреть подтверждение поездки.
Просьба не подтверждать реальный заказ машины.
