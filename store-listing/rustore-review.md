# Доступ для модерации RuStore

Перед **каждой** отправкой версии на модерацию выполнить:

```sh
npm run review:rustore
```

Команда проверяет вход, профиль пассажира и обновление сессии на
`https://api.taxigr.ru`, затем создаёт актуальный текст в
`tmp/store-release-<version>/moderator-comment.txt` и квитанцию проверки
`rustore-review.json`. Телефон и код берутся из `server/play-review-auth.ts`.

Вставлять этот текст в **«Комментарий модератору»** (API: `moderInfo`) при
каждой публикации, включая повторную отправку и переход из API в консоль.
Проверять сохранение текста в самой отправляемой версии и фиксировать это
в квитанции релиза. Ссылка на этот документ не заменяет текстовые данные входа.
Ограничение API: 180 символов. Данные доступа не помещать в публичное описание
приложения или «Что нового».

## Тестовая учётная запись

- Телефон: `+7 999 888-77-66`.
- Постоянный код подтверждения (вместо пароля): `4455`.

1. Нажмите «Войти по SMS» под кнопками мессенджеров.
2. Нажмите «Принять и продолжить», если показано согласие.
3. Введите `9998887766`: код страны `+7` уже указан.
4. Нажмите «Получить код по SMS».
5. Введите `4455` и нажмите «Подтвердить код».

Получать SMS или входить во внешние аккаунты VK, MAX и Telegram не требуется.
Аккаунт имеет только роль пассажира, профиль заполнен. Оплата и подписка
для входа не нужны. Просьба не оформлять реальную поездку при проверке.

на рабочем сервере перед повторной подачей после отклонения 1.0.20 (40).
