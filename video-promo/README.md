# Motion-ролик «Такси Грахово»

Актуальная композиция — **«Закажи в одно касание»**: 32 секунды, 1080 × 1920, 60 fps. Полноэкранная карта с настоящими 3D-зданиями, машиной, меткой назначения и пульсацией местоположения. В сцене водителя — объёмная лупа с читаемым номером. В финале — TAXIGR.RU, одинаковая видимая высота значков RuStore / Google Play и подпись «Доступно в VK, MAX и Telegram».

В монтаже от 29.10.2026 используется третий, последний дубль Павла и предоставленная пользователем музыка «Призыв». Прежняя озвучка и все старые звуковые эффекты отключены. Между фразами добавлены паузы; смены сцен и появления элементов финала привязаны к новой записи. Лупа появляется вместе с карточкой водителя; автомобиль на карте движется только к назначению. В финале — «Грахово и межгород 24/7» и телефон небольшой строкой.

## Смотреть

Текущий монтаж: `npm run studio`, композиция `TaxiGrahovoSignature`. Итоговый файл: `out/signature/taxigr-signature-1080x1920-60fps.mp4`.

```powershell
node scripts/serve-signature.mjs
```

Команда выводит локальный адрес страницы с проигрывателем, главами и скачиванием. Постер: `out/signature/poster.jpg`. Результаты технической проверки: `out/signature/verification.json`.

## Редактировать и собирать

Композиция **TaxiGrahovoSignature** находится в `src/SignaturePromo.tsx`, сценарий и тайминг — в `design-spec-signature.md`.

```powershell
npm run studio
npm run typecheck
npm run render
```

Финальная сборка обрабатывает голос, собирает музыкальную подложку с приглушением под речь, рендерит видео, переводит цвет в BT.709, выравнивает громкость, проверяет декодирование и создаёт страницу просмотра. Для сведения и проверки требуется полный FFmpeg с фильтрами `afir`, `loudnorm` и `zscale`. Путь задаётся через `FFMPEG_PATH`; `FFPROBE_PATH` необязателен. На текущем рабочем компьютере используется локальный FFmpeg из `../tmp/media-tools/imageio_ffmpeg/binaries/`.

Источник монтажа и точные границы фраз: `signature-edit.json`. Исходный третий дубль выделен по встроенной главе WAV 40,344671–62,229478 с; его темп, высота голоса и слова не изменены. Применены эквализация, мягкая компрессия, деэссер и короткая стереореверберация. Обработанный голос и музыка остаются отдельными дорожками. Отчёт о сведении: `out/pavel-voice/audio-edit-report.json`.

Для рендера на этом компьютере: `$env:REMOTION_BROWSER_EXECUTABLE='C:/Program Files/Google/Chrome/Application/chrome.exe'`. По умолчанию используется аппаратный ANGLE; при необходимости `REMOTION_GL` позволяет выбрать другой поддерживаемый рендерер. Без пути браузера Remotion скачает Chrome Headless Shell.

Для быстрой проверки монтажа: `npm run preview:signature`. Для кадров сцен: `node scripts/render-signature.mjs frames`.

Прежние ролики и композиции сохранены. Старую минутную горизонтальную версию можно собрать через `npm run render:legacy`.
