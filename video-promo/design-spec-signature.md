# Закажи в одно касание

Переработка существующего пассажирского ролика от 9 сентября 2026.

## Формат и монтаж

1080 × 1920, 60 fps, 32 секунды. Исходная пользовательская дорожка `audio/user/taxi-grahovo-voice.mp3` сохранена. Длина дорожки 29,76 секунды; финальный титр остаётся до 32 секунд. Сцены синхронизированы с прежними смысловыми границами речи.

| Время | Сцена | Движение |
| --- | --- | --- |
| 0–4,5 | Закажи в одно касание. Такси в любое место. | Поворот объёмного телефона с актуальным экраном, жёлтый маршрут, вылетающий адрес |
| 4,5–7,2 | Заказ | Появление двух адресов, тарифы с актуальными иллюстрациями, нажатие кнопки |
| 7,2–11,6 | Вы видите водителя: кто к вам едет и когда приедет | Выезд автомобиля, отступ перед карточкой Дмитрия, настоящая 3D-лупа с читаемым номером |
| 11,6–19,6 | Всё на карте. До самой точки. | Полноэкранная Three.js-сцена, объёмные здания и метка назначения, движение машины, пульсация местоположения |
| 19,6–26,27 | Оценка | Объёмные звёзды, набор отзыва, подтверждение отправки |
| 26,27–32 | Финал | TAXIGR.RU по центру простым текстом; RuStore и Google Play одинаковой видимой высоты; небольшая подпись «Доступно в VK, MAX и Telegram» |

## Дизайн

- Локальный Manrope с кириллицей, фирменный знак из `public/logo.svg`.
- Жёлтый #F6C945, графит #171915, тёплый светлый #F7F4EB.
- Каждая сцена ставится отдельно: это новый монтаж, а не перекраска прежнего ролика.
- Весь motion рассчитывается по времени кадра; системные CSS-анимации не используются.
- Траектория машины и видимая линия используют общую кривую Catmull–Rom. Здания, машина, лупа и метка назначения — геометрия Three.js с освещением; карта использует ортографическую камеру под углом.
- Водитель и поездка — демонстрационный пример; рекламные отзывы от вымышленных пользователей не добавляются.
- В финале показаны оба магазина по запросу пользователя. Сайт не оформлен как кнопка, стрелка и прежний финальный слоган убраны.

## Звук и исходники

Пользовательская озвучка/музыкальная дорожка сохранена без изменения слов и скорости. Лёгкие переходы, касания, звёзды и финальный аккорд синтезированы локально скриптом `scripts/generate-signature-audio.mjs`. Старый сторонний BGM не используется. Новые шрифты, изображения и звук находятся в `public/signature/`; прежние композиции сохранены.

```powershell
node scripts/generate-signature-audio.mjs
npm run typecheck
node scripts/render-signature.mjs frames
npm run preview:signature
npm run render:signature
```

Основная композиция: `TaxiGrahovoSignature`, исходник: `src/SignaturePromo.tsx`.
