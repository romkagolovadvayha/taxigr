# Запросы такси из чужих групп: пробный запуск

Получатель — только администратор, создавший подключение Android. Используются его
привязанные боты MAX, Telegram и VK с включёнными уведомлениями. Рассылка водителям
не реализована и не включена. Сообщение из группы не создаёт заказ такси автоматически.

## Подключение

1. Подготовить отдельный Android 9 или новее. Войти в MAX своим аккаунтом и подключить
   WhatsApp как дополнительный телефон. У аккаунта уже должен быть доступ к нужным группам.
2. В своём профиле сервиса включить уведомления в нужных ботах. Затем открыть
   **Администрирование → Настройки → Сообщения из групп**.
3. Указать названия групп отдельно для MAX и WhatsApp, каждое с новой строки. Названия
   должны совпадать с уведомлениями телефона. Группы с одинаковыми названиями этот
   способ отличить не может: не подключать неоднозначные названия.
4. Нажать **Получить код для Android**. Одноразовый код действует 10 минут.
5. Скачать [APK «Группы такси» 0.1.0](https://taxigr.ru/tools/taxigr-groups-0.1.0.apk)
   кнопкой в админке. Установить приложение, ввести код и явно разрешить доступ
   к уведомлениям в настройках Android. Для APK, установленного из браузера, Android
   может сначала потребовать «Разрешить ограниченные настройки» в сведениях о приложении.
6. Оставить телефон включённым и с интернетом. В MAX и WhatsApp разрешить показ текста
   уведомлений выбранных групп. На самом телефоне проверить обычное новое сообщение,
   сообщение с заблокированным экраном, восстановление интернета и повтор уведомления.

Приложение получает системный доступ к уведомлениям, но сохраняет и отправляет только
сообщения из выбранных групп официальных пакетов MAX/WhatsApp, подходящие под фильтр
запросов такси. Личные диалоги, прочие приложения и содержимое остальных групп не передаются.
Приложение ничего не пишет в исходные группы и не хранит пароль или сессию мессенджера.

## ФИО и телефон

Сервер может добавить **имя в том виде, как оно сохранено в базе**, и подтверждённый
телефон, если Android-уведомление содержит однозначный `Person.uri` вида `tel:+...`
именно у автора сообщения и этому номеру соответствует ровно один действующий аккаунт.
Телефон из текста сообщения, отображаемое имя и совпадение ФИО не используются как
доказательство личности. Мессенджеры могут не передавать номер автора в уведомлении.
В таком случае придёт текст и имя из группы с пометкой, что автор не определён надёжно.
Идентификаторы MAX не угадываются из внутренних ключей уведомлений. Возможность получить
их проверяется отдельно на фактическом уведомлении телефона; пока этот путь не включён.

## Надёжность и отключение

- Обновления одного уведомления отсеиваются по идентификатору события на телефоне
  и уникальному ключу на сервере. Локальная очередь — максимум 100 сообщений не старше часа.
- Ключ устройства и очередь зашифрованы ключом Android Keystore, резервное копирование
  и перенос данных отключены. Устройство может только передавать сообщения и читать
  свой список групп; сведения о пользователях ему не возвращаются.
- Сервер отправляет в боты через устойчивую очередь с отдельным состоянием для каждого
  канала. Повторяется только неуспешная доставка. При аварии между отправкой в мессенджер
  и записью результата возможен повтор — API мессенджеров не дают общей транзакции.
- Текст на сервере хранится семь дней. Повторные попытки отправки прекращаются через сутки
  либо после 12 попыток. Удаление пользователя каскадно удаляет его подключения и события.
- Пауза на Android останавливает чтение и отправку. **Отключить устройство** в админке
  отзывает ключ и запрещает доставку оставшихся событий. Утрата прав администратора
  и блокировка аккаунта также прекращают приём и рассылку.

## Сборка и проверки

`companion-android` — отдельное небольшое нативное Java-приложение, не часть APK клиентов
такси. Основному приложению не добавляется доступ к чужим уведомлениям.

С JDK 17 и Android SDK 36:

```powershell
./companion-android/gradlew.bat -p companion-android :app:assembleRelease :app:testDebugUnitTest :app:lintRelease
npm run typecheck
npm test
npm run lint
```

Release APK необходимо подписать отдельным ключом сборщика. Закрытый ключ не должен
попадать в репозиторий. Сервер требует миграцию `054_group_alerts.sql`.

Интеграционные проверки с настоящей отдельной MySQL-базой запускаются с
`RUN_GROUP_ALERT_INTEGRATION=1` и `MYSQL_URL`, содержащим `/taxi_qa_` или `/taxi_test_`:

```text
npx vitest run tests/group-alerts.integration.test.ts
```

Перед использованием на настоящем Android обязательна проверка формата уведомлений
установленных версий MAX и WhatsApp. Обрезанные, скрытые, объединённые и вовсе
не созданные мессенджером уведомления не позволяют гарантировать получение всех сообщений.
