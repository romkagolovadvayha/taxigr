# Рассылки ВК

Раздел `/admin/broadcasts` доступен администраторам сервиса. Сообщества «Такси Грахово» и «Афиша Грахово» имеют отдельные аудитории, черновики и очереди.

1. Выберите сообщество и обновите аудиторию. Проверяются участники, обычные и архивные личные диалоги, привязанные аккаунты и сохранённые разрешения. Запретившие сообщения исключаются. Результат действителен 24 часа.
2. Введите название для истории, текст до 3500 символов и при желании загрузите картинку. Клиент уменьшает её до 1600 px и 2,5 МБ. Сервер принимает JPEG/PNG. Кнопка заказа открывает мини-приложение такси в ВК.
3. Отправьте тест. Получатели определяются сервером: только действующие администраторы сервиса с привязанным ВК и разрешением получать сообщения выбранного сообщества. Перед отправкой роль проверяется повторно.
4. Для общей рассылки отдельно подтвердите количество получателей. После запуска содержание фиксируется; для новой отправки используйте копию. История показывает последние 30 запусков и 50 сообщений.

Очередь находится в MySQL и продолжает работу после закрытия страницы и перезапуска API. На получателя выделяется постоянный ненулевой `random_id`, повторный запрос запуска не создаёт копию очереди. Один воркер на сообщество обеспечивается advisory lock MySQL. Внешние запросы выполняются только при активной задаче, с паузой не менее 550 мс между запросами одного шага. Проверки разрешений объединяются по 25 в `execute`; отправка выполняется по одному получателю с повторной проверкой разрешения. Сетевые ошибки откладывают весь запуск; ограничения рассылок и ошибки ключа останавливают его. Повторный тест возможен не чаще раза в минуту.

Кнопка остановки прекращает следующие отправки. Уже переданный ВК запрос может завершиться после остановки. «Отправлено» означает подтверждение API ВК, а не прочтение человеком. Веб-страница обновляет статус раз в 5 секунд только при активной задаче и на видимом экране.

Настройки сервера:

- `VK_COMMUNITY_ID` / `VK_BOT_TOKEN` — существующее сообщество такси.
- `VK_AFISHA_COMMUNITY_ID=45653506` / `VK_AFISHA_BOT_TOKEN` — Афиша Грахово.

Ключи должны быть ключами соответствующих сообществ с доступом к сообщениям, фотографиям и чтению участников. Значения не возвращаются в админку. Для Gitlub используются одноимённые Variables/Secrets с префиксом `PRODUCTION_`; ключ хранится именно в Secrets.

Миграция `058_vk_broadcasts.sql` добавляет отдельные таблицы; существующие API заказов и авторизации не меняются. Интеграционные тесты `tests/vk-broadcasts.integration.test.ts` требуют `RUN_BROADCAST_INTEGRATION=1` и локальную базу с префиксом `taxi_test_`; запросы к ВК заменяются заглушкой. Запуск на production запрещён проверкой адреса базы.
