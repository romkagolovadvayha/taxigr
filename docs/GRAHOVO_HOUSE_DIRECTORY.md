# Дома Граховского района — обновление 11 сентября 2026

Причина перехода к карте: старый справочник содержал номера домов из ГАР, но
координаты большинства записей были центрами улиц или населённых пунктов.
Наличие номера в ГАР не подтверждает положение конкретного здания.

## Что загружено

| Данные | Количество |
| --- | ---: |
| Исходный ГАР, снимок 03.08.2026: дома, здания и сооружения | 4 266 |
| Населённые пункты, территории и улицы | 272 |
| Уникальные адреса с координатами из OpenStreetMap | 550 |
| Из них сопоставлены с ГАР | 528 |
| Дополнительные адреса, отсутствующие в снимке ГАР | 22 |
| Итоговый каталог, включая улицы и населённые пункты | 4 560 |

В Грахово добавлены точки **519 домов**. Остальные 31 адрес распределены между
Иж-Бобьёй, Каменным, Лолошур-Возжами, Мари-Возжаем, Мишкиным, Порымом, Старой Игрой,
Верхней Игрой и Новогорским. Каталог содержит 4 288 адресных объектов с номерами;
у 3 738 из них в импортированном снимке остаются приблизительные точки.
Ранее заданные отдельные точки известных мест в приложении сохранены.

Источники: [ГАР ФНС](https://fias.nalog.ru/) и
[OpenStreetMap](https://www.openstreetmap.org/copyright), граница района —
[relation 956094](https://www.openstreetmap.org/relation/956094).
Снимок OSM: **2026-09-11T00:27:59Z**, лицензия ODbL-1.0.
Для каждой импортированной точки сохранена ссылка на исходный объект OSM.

Из 575 исходных адресных объектов 17 объединены как близкие дубли, 8 отклонены
из-за неоднозначного населённого пункта, адреса или конфликта координат.
Импорт сопоставляет номер и улицу с населённым пунктом по его полигону либо явному
адресному тегу. Он не раздаёт номера непронумерованным зданиям, не интерполирует
номера вдоль улицы и не помечает центр села как точку дома.

## Поиск и выбор

- Клиент и API используют единый дополненный каталог. Дом с известной точкой
  можно выбрать сразу, без обязательного клика на карте.
- Запрос номера 1 не показывает дома 10 или 19 и организации в другом доме.
- При выборе дома с приблизительной точкой выполняется отдельная проверка
  геокодера (`kind=house`). Только совпадение номера, улицы и населённого пункта
  в допустимой близости может заменить приблизительный адрес.
- Если точной точки нет, остаётся выбор на карте. Отмена или смена запроса
  отменяет уточнение и не подставляет результат старого поиска.

**Благодатное, Благодатновская, 1:** номер присутствует в ГАР, но его геопозиция
не найдена в доступном снимке OSM и при дополнительном запросе Nominatim.
Запись сохранена как приблизительная. Достоверно заполнить координаты всех
остальных домов без дополнительного источника адресных точек невозможно.
Попытка обращения к публичному поиску НСПД завершилась таймаутом соединения;
данные оттуда не импортировались.

## Обновление и установка

### Запоминание отмеченных домов

Кнопка «Подтвердить и запомнить» сохраняет номер, полный адрес и выбранную
точку через авторизованный `POST /v1/addresses/points`. Миграция
`047_remembered_address_points.sql` добавляет отдельную таблицу
`remembered_address_points`: импорт ГАР/OSM её не изменяет.
Сохранённые точки доступны другим пассажирам через обычный поиск, в том числе
после перезапуска API. Поиск читает их до обращения к кэшу внешнего геокодера.
Встроенные приблизительные записи заменяются сохранёнными точками, а известные
точки OSM сохраняют приоритет. Источник в адресе — «точка выбрана на карте».

Ключ учитывает населённый пункт, улицу/переулок и номер с суффиксом. Регистр,
сокращения и `ё/е` не создают дублей. Подтверждение дальше 15 км от исходного
адреса отклоняется. Повторная отправка не создаёт дубликат; если точка для этого
адреса уже сохранена дальше 80 м от новой, API возвращает конфликт и не изменяет
первую запись. При ошибке экран сохраняет выбранную точку и предлагает повторить
сохранение. Удаление аккаунта убирает связь с автором, сохраняя адресную запись.

В деморежиме адреса сохраняются только на этом устройстве (в браузере — в
localStorage, на мобильном устройстве — в SecureStore), без записи в общую базу.
Они восстанавливаются после перезапуска приложения и дополняют локальный поиск.
Очистка данных приложения/браузера удаляет демоадреса.

```sh
# Получить свежие адресные объекты OSM района и сформировать каталог точек.
npm run addresses:osm
# Либо воспроизвести импорт из сохранённого ответа Overpass:
npm run addresses:osm -- path/to/overpass-response.json

# Выполнить на целевой базе с её MYSQL_URL:
npm run db:migrate
npm run db:addresses
```

Миграция `046_address_directory.sql` создаёт таблицу с точностью координат,
источником и датой снимка. Импорт выполняется транзакцией; повторный запуск
обновляет записи без дубликатов. После импорта перезапустите API: каталог
кэшируется в памяти процесса. При недоступной базе работает встроенная копия.
Клиент нужно пересобрать для обновления локальных подсказок.
Production-деплой автоматически запускает миграции и импорт до включения
нового релиза. Выбранные пользователями точки хранятся в отдельной таблице
и сохраняются при обновлении справочника.

Снимок: `src/data/grahovo-house-points.json`. Скрипт также сохраняет
`tmp/grahovo-house-import-report.json` со списком отклонённых объектов и адресов
без координат. Применено к локальной тестовой базе на порту 3317; боевой сервер
в этом сеансе не обновлялся.

## Проверка

Прошли 583 модульных/компонентных теста и 36 интеграционных тестов API,
проверки TypeScript и ESLint. Импорт повторно выполнен: осталось 4 560 активных
записей, из них 550 с точными координатами.
В интеграционном тесте маршрут между Колпакова, 8 и Ачинцева, 16 рассчитан
из импортированных точек; проверены номер дома и отсутствие неверных подсказок.
В браузере Колпакова, 8 выбрана сразу и появилась в поле подачи без экрана выбора
точки. По запросу Благодатновская, 1 показан только дом 1; после дополнительной
проверки геокодера сохранился корректный переход к карте. Обе веб-сборки обновлены.

Запоминание проверено в отдельных вкладках демо и обычного тестового аккаунта:
ручной ввод → карта → подтверждение → перезагрузка страницы → поиск → выбор
без повторной отметки. Через SQL и API подтверждено, что точка пережила
перезапуск API и повторный импорт всех 4 560 записей. Синтетический дом
«Тестовая Память, 999999» удалён из тестовой базы после проверки; действительные
координаты Благодатновской, 1 не подменялись. В проверенном сценарии ошибок
JavaScript в браузере не было.
