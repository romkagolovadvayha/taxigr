# Публичная главная: «Свои дороги. Своё такси»

Новая веб-версия главной реализована в `src/screens/public-landing-screen.web.tsx` и `src/screens/public-landing.css`. Она отображается на `/` для посетителей без авторизации. После входа открывается привычный экран заказа.

## Визуальная концепция

Молочный фон, фирменный жёлтый #F6C945 и графит #25231E, существующий знак маршрута, крупная типографика и реальные экраны приложения в объёмных корпусах телефонов. Анимированная лупа увеличивает расчётную стоимость. Телефон реагирует на курсор и прокрутку; блоки мягко появляются при прокрутке. Жёлтая версия обновлена 9 сентября 2026 года.

Порядок страницы: короткое обещание сервиса → три переключаемых этапа заказа → два тарифа → география поездок → водителям → ответы на вопросы → заказ.

## Материалы

- `app-home.png`, `app-route.png`, `app-driver.png` — снимки текущего приложения из локального демо-сеанса на 390×844, с плотностью 2×. Адреса, водитель и цена относятся к демонстрационному заказу.
- `public/landing/*.webp` — оптимизированные изображения для сайта. Общий объём шести изображений около 405 КБ.
- `economy-car.webp`, `child-seat.webp` — новые иллюстрации жёлтого такси с шашками и графитово-жёлтого детского кресла.
- `local-roads.webp` — созданная для страницы 3D-иллюстрация села и жёлтого маршрута.
- `desktop-hero.png`, `desktop-full.png`, `mobile-hero.png`, `mobile-full.png` — проверенные снимки готовой страницы. Снимки статичны; движение видно в работающей версии.

## Проверка

TypeScript, ESLint и production export Expo прошли. Браузерная проверка покрывает ширины 320, 390, 768, 1024 и 1440, загрузку изображений, выбор этапа и тарифа, раскрытие вопросов, остановку и запуск анимации, `prefers-reduced-motion` и переход к входу. Результаты сохранены в `verification.json`.

Анимация выполняется на CSS и requestAnimationFrame, без дополнительных библиотек 3D. Настройка уменьшенного движения отключает анимацию и параллакс. В подвале есть ручная остановка движения. Контент и ссылки доступны с клавиатуры.

Для повторения локальной проверки установите `TAXI_PLAYWRIGHT_PATH` в путь доступного пакета Playwright и запустите `node docs/design/verify-landing.cjs`. Необязательная переменная `TAXI_LANDING_URL` задаёт URL проверяемой сборки. Скрипт `capture-landing-demo.cjs` снимает только локальный демонстрационный заказ, а `serve-landing-preview.cjs` показывает каталог `dist` на `http://127.0.0.1:8090/`.

Новая версия подготовлена локально. Публикация на taxigr.ru не выполнялась в рамках этой правки.
