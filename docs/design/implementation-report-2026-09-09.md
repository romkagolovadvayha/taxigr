# Внедрение «Тихого движения»

9 сентября 2026. Согласованный дизайн перенесён из HTML-концепции в рабочее Expo-приложение.

Приложение запущено по адресу http://localhost:8081/sign-in, локальный API — http://127.0.0.1:4100. На экране входа после согласия с условиями доступны демо-роли пассажира, водителя и суперадминистратора. База MySQL доступна, `/health/live` возвращает `ok`, `/health/ready` — `ready`.

## Что изменено

- Светлая синяя и тёмная палитры, Manrope, более спокойные начертания, новые радиусы и тени применяются во всех экранных модулях через общие компоненты и токены.
- Геометрия исходного логотипа сохранена; основной цвет — `#315DD5`, символы белые. Обновлены иконки приложения, заставка, PWA, favicon, social preview и офлайн-страница.
- Карточки «Эконом» и «Детский» используют согласованные иллюстрации WebP. Название и подпись центрированы под изображением; реальные цены и время подачи сохранены. Индикатор выбора плавно перемещается, выбранная иллюстрация немного приподнимается.
- Общий компонент госномера показывает буквы и цифры, отдельный регион, RUS и маленький флаг. Нестандартные номера остаются текстом: регион не выдумывается. Компонент используется в активной поездке, профиле водителя и деталях заказа администратора.
- Все экраны подписаны на реактивную палитру. Переключение темы больше не пересоздаёт навигацию. Карта меняет тему на месте; WebView сохраняет исходный HTML, новые цвета поступают сообщением. Изменение только темы не сбрасывает камеру.
- На небольшом экране содержимое панели пассажира прокручивается, чтобы иллюстрации не закрывали доступ к действиям.
- Нажатия, переходы и выбор тарифа учитывают системную настройку уменьшения движения.

Исходные маршруты, формы, обработчики поездок и API сохранены. HTML-концепция в этой папке остаётся отдельным демонстрационным артефактом.

## Границы проверки

Первый обход выполнен на встроенных демо-данных. Повторная проверка использует отдельную временную MySQL-базу и локальный API с искусственными пользователями: 33 интеграционных теста и браузерные сценарии чата и справочника. Существующая рабочая база не использовалась для этих записей. Доставка через внешние провайдеры входа и push, звонки, GPS и фоновая навигация не проверялись с реальными пользователями или телефонами. Экспорт Android/iOS проверяет сборку JavaScript и ресурсов, а не установку APK/IPA и работу на устройстве.

В повторном браузерном тесте зарегистрирована отмена запроса покрытия карт сторонней библиотекой Яндекс при изменении размера/навигации (`The user aborted a request`); запись сохранена в `functional-browser-verification.json`. Прикладные сценарии завершились успешно. Доступ к OSRM для интеграционного набора проверен отдельно: первый запуск в сетевой песочнице дал 32/33, повтор с доступной сетью — 33/33.

Во время обхода страниц отменённые при навигации сетевые запросы сохранены в JSON-отчёте; один запрос к локальному API был сделан до его запуска. Для запущенного локального API используется console SMS, внешние токены отправки отключены только в окружении его процесса. Файлы `.env` не менялись. На внешний сервер приложение не публиковалось.

Для повторной проверки используются локальные CLI: `node node_modules/typescript/bin/tsc --noEmit`, `node node_modules/eslint/bin/eslint.js src`, `node node_modules/vitest/vitest.mjs run` с `RUN_API_INTEGRATION=0`, `node node_modules/expo/bin/cli export --platform all` с `EXPO_PUBLIC_DEMO_MODE=false`. Демо-запуск интерфейса: `EXPO_PUBLIC_DEMO_MODE=true`, затем `node node_modules/expo/bin/cli start --web --port 8081 --offline`.
