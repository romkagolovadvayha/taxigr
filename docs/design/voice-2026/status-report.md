# Озвучка статусов — 9 сентября 2026

Заменён голос и добавлены недостающие события. 29 записей голосом `ru-RU-DmitryNeural`, без ускорения и изменения высоты. Фразы записаны целиком, с естественными паузами; персональные данные не передаются синтезатору. MP3 для приложения, WAV для системных push. Манифест: `assets/sounds/voice-manifest.json`.

| Событие | Озвучка |
| --- | --- |
| Создание заказа пассажиром | Ищем водителя. Пожалуйста, ожидайте. |
| Водитель назначен | Водитель найден. |
| Назначен занятый водитель | Объяснение, что он завершает предыдущую поездку |
| Водитель освободился | Скоро отправится к пассажиру |
| Выезд, прибытие, начало поездки | Отдельные записи для пассажира и водителя |
| Завершение | Наличные/перевод по данным заказа, просьба оценить поездку/пассажира |
| Отказ водителя | Пассажиру — поиск другого водителя; водителю — подтверждение отказа |
| Отмена пассажиром | Водителю — «Пассажир отменил заказ» |
| Отмена администратором / истекло время поиска | Отдельные объяснения |
| Новый заказ водителю | Предложение принять или отклонить |
| Заказ принят | Пассажир ожидает, можно позвонить или написать для уточнения деталей |
| Следующий заказ принят | Сначала нужно завершить текущую поездку |
| Следующий заказ стал текущим | Можно ехать к следующему пассажиру |
| Повышение цены, входящий чат | Отдельные записи |

Восстановленные заказы и обновления координат не повторяют старые статусы. Дубли из нескольких подписок подавляются; повторное назначение после отказа снова озвучивается. Новое состояние того же заказа заменяет устаревшую реплику. Разные заказы и чат воспроизводятся по очереди, без наложения. Отключение звука, уход в фон и выход из аккаунта очищают очередь.

События передаются диктору до объединения обновлений React: завершение текущего заказа не теряется при одновременном продвижении следующего, а отмена следующего заказа не теряется при удалении карточки.

Проверено:

- 475 автоматических тестов прошли; 46 тестов API-интеграции пропущены (изолированный API/БД не запускались в этой проверке).
- TypeScript, ESLint и production web export прошли.
- Реальное декодирование и воспроизведение MP3 в Edge: проверка голоса, мгновенное выключение, повтор из кеша, без ошибок JavaScript.
- Пассажир: шесть уведомлений через полный цикл поездки, отдельно наличные и перевод, включая просьбу оценить.
- Водитель: десять уведомлений через принятие, выезд, прибытие, поездку, принятие следующего заказа, завершение и продвижение следующего, затем отказ. Завершение прозвучало полностью перед следующим заказом.
- Правила отмен, повторного поиска, дублей, очереди и native callback завершения проверены тестами. Нативное устройство не использовалось.

Подробные результаты: `browser-verification.json` и `status-verification.json`. Сценарии: `docs/design/verify-voice.cjs`, `docs/design/verify-voice-statuses.cjs`.
