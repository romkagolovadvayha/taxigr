# Загрузка фотографий тарифов — 9 сентября 2026

Уменьшены утверждённые фотографии без изменения оформления. Исходные PNG сохранены; скрипт `scripts/optimize-tariff-assets.mjs` воспроизводит WebP из них.

| Фотография | Ранее | Карточка 44 px (192×128) | Крупная иллюстрация (384×256) |
| --- | ---: | ---: | ---: |
| Эконом | 43 542 байта, 740×493 | 5 112 байт | 13 214 байт |
| Детский | 26 376 байт, 740×493 | 3 414 байт | 8 078 байт |

Две фотографии в компактных карточках занимают 8 526 байт вместо 69 918 (на 87,8% меньше). Размер учитывает экраны с высокой плотностью пикселей.

Expo Image 57 по умолчанию использовал отложенную загрузку в браузере. Для тарифов включены `loading="eager"`, высокий приоритет, отсутствие перехода при появлении и кеш в памяти/на диске для нативного приложения. HTML начинает предварительную загрузку двух компактных изображений до выполнения приложения. Preload использует тот же Expo asset URL, что и компонент, без дублирования файлов в public.

Проверка в чистых контекстах Edge: вход демо-пассажира и открытие с сохранённой сессией, каждый раз без предыдущего кеша. При искусственной задержке запросов фотографий на 700 мс обе загрузки завершились до появления карточек. Фотографии отрисовались через 74 и 42 мс после появления контейнера соответственно; ошибок JavaScript нет. На подтверждении используются те же компактные изображения, переключение тарифа работает. Проверена чёткость на ширинах 320 и 390 px при DPR 3.

Metro в режиме разработки явно отправляет `Cache-Control: no-store`, поэтому повторное монтирование экрана может повторять запросы изображений даже с `cachePolicy`. Это ограничение dev-сервера. Конфигурация production Nginx включает кеширование WebP. Проверка не подменяет поведение Metro искусственными кеширующими заголовками.

Результаты браузерной проверки: `verification.json`. Снимки: `tariffs-320.png`, `tariffs-390.png`, `confirmation-tariffs.png`. Проверки пяти тестов изображений, TypeScript и ESLint прошли.

Production web export прошёл. В HTML авторизации и подтверждения preload ссылается на существующие файлы с хешем в имени, 5 112 и 3 414 байт. Демо-сервер после сборки снова запущен на порту 8082.
