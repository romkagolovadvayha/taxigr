# Проверка сохранности функционала после редизайна

9 сентября 2026. Проверено рабочее Expo-приложение на http://localhost:8081, а также его HTTP API, MySQL и сокеты. HTML-макет на порту 8899 остаётся демонстрацией дизайна.

## Сверка с исходной версией

Базовая ревизия: `eaeb0ac40b990f8571d9a9c869cccf06741bc313`.

- Сохранены все 34 экранных модуля, 44 файла маршрутов и 222 существующих TypeScript-модуля клиента. Удалённых файлов нет.
- Сравнены 967 JSX-привязок: обработчики, переходы, ограничения и значения полей, видимость, защита маршрутов, выделение текста. Обработчики действий и значения форм не удалены. Три отличия по количеству `selectable` объясняются переносом номера в общий компонент и объединением двух вариантов заголовка тарифа.
- Сравнены 73 именованные функции экранов после исключения JSX и подключения палитры: 72 совпадают. Единственное отличие — параметр `showTitle` панели бронирования; условия расчёта, состояния и обработчики внутри неё сохранены.
- Файлы API, авторизации, hooks, state, storage, существующей предметной логики, правовых документов, providers, config и сервера совпадают с исходной ревизией. Добавлен отдельный парсер номера.

Автоматическая сверка исходников — свидетельство сохранности связей и логики, а не доказательство всех возможных состояний исполнения. Её дополняют тесты и браузерные сценарии ниже.

Данные сверки: [functional-preservation-audit.json](functional-preservation-audit.json).

## Исправления по результатам проверки

- Детский тариф снова показывает фактическое время подачи рядом с подписью «С креслом».
- Текст тарифов, основная часть номера и регион доступны для выделения.
- Выбор наличных/перевода явно сообщает состояние `aria-checked` браузеру и средствам доступности.

После проверки временные API-процессы остановлены, созданная тестовая база удалена. Основное локальное приложение и API на портах 8081/4100 продолжают работать.

## Практические ограничения

Доставка настоящих SMS/сообщений провайдеров, push на телефоны, звонки, системные разрешения камеры/GPS и фоновая работа на физических Android/iOS требуют отдельной проверки на устройствах. Их исходные интеграции сохранены; утверждать, что они проверены на реальных телефонах, нельзя.

В проверке Яндекс.Карт библиотека сообщила об отменённом запросе покрытия при изменении размера/навигации. Событие не скрыто: сохранено отдельно в браузерном JSON. Основные сценарии успешно завершены. Сетевой доступ к OSRM потребовался для одного интеграционного теста; при доступной сети прошли все 33 теста.

Потерь исходных действий и разделов в ходе этой проверки не обнаружено. Найденные небольшие потери отображения исправлены.
