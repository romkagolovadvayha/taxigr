# 1.0.22 (42): поиск водителя и подтверждение прибытия

Во время поиска водителя у точки подачи отображаются три расходящихся импульса.
Радар привязан к координатам подачи, отключается после назначения водителя
и учитывает уменьшение движения. Реализован для web и нативной карты.

«Я на месте» запрашивает свежую геопозицию и передаёт её вместе с переходом
статуса. Сервер проверяет координаты и подтверждает прибытие в одной транзакции,
независимо от ограничения частоты фоновых запросов. Сохранены проверка близости
к подаче, принадлежности заказа и актуальности геопозиции. Если GPS временно
не отвечает, допускается только действительно недавняя позиция; отсутствие
координат не заменяется координатами пассажира.

Обновления координат больше не требуют перемещения автомобиля. Ошибка настройки
фонового режима и недоступность последней известной позиции не останавливают
запуск геолокации на открытом экране.

Проверки перед выпуском: TypeScript, ESLint, 716 модульных тестов,
38 сценариев API на отдельной локальной базе, production web export.
В Edge с тестовыми ответами API проверены движение и остановка радара,
уменьшение движения, мобильный/широкий экран и отправка геопозиции при
подтверждении прибытия. Физическое устройство не использовалось.

Артефакты, журналы сборок и квитанции публикации: `tmp/store-release-1.0.22/`.
