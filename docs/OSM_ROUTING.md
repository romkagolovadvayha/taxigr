# Бесплатная маршрутизация и геокодирование

«Такси Грахово» не использует платные API Матрицы расстояний или Геокодера
Яндекса. Яндекс JavaScript API остаётся только клиентским слоем отображения
карты.

## Маршруты

Сервер обращается к собственному контейнеру OSRM через `ROUTER_BASE_URL`.
OSRM рассчитывает автомобильное расстояние и продолжительность по данным
OpenStreetMap. Результаты кэшируются в памяти на 10 минут.

Если OSRM перезапускается, не успевает ответить за 2,5 секунды или не содержит
нужный регион, API автоматически использует консервативную оценку по прямому
расстоянию с дорожным коэффициентом. Создание заказа при этом не блокируется.

Подготовка данных на Windows:

```powershell
powershell -ExecutionPolicy Bypass -File deploy/osrm/prepare.ps1
docker compose --env-file .env.production up -d --build
```

Linux/macOS:

```bash
sh deploy/osrm/prepare.sh
docker compose --env-file .env.production up -d --build
```

Первый запуск скачивает актуальный OSM-экстракт Приволжского федерального
округа и строит автомобильный граф. Потребуется около 1 ГБ для загрузки,
несколько гигабайт диска для подготовленных файлов и достаточно памяти на
этапе обработки. Данные находятся в `deploy/osrm/data` и не попадают в Git.

Для безопасного обновления остановите `osrm`, запустите подготовку с флагом
обновления и снова поднимите контейнер:

```powershell
docker compose --env-file .env.production stop osrm
powershell -ExecutionPolicy Bypass -File deploy/osrm/prepare.ps1 -Refresh
docker compose --env-file .env.production up -d osrm
```

На Linux/macOS используйте `sh deploy/osrm/prepare.sh --refresh`. Новый PBF
сначала загружается во временный файл, поэтому оборванная загрузка не повреждает
рабочий граф.

## Адреса

Сначала проверяется встроенный локальный справочник Грахово. Остальные адреса
запрашиваются у публичного Nominatim только после явного нажатия пользователем
кнопки поиска:

- не более одного внешнего запроса в секунду;
- идентифицирующие заголовки `User-Agent` и `Referer`;
- кэш в MySQL и памяти на 30 дней;
- атрибуция OpenStreetMap в интерфейсе;
- отсутствие автоматических запросов при каждом введённом символе.

При росте нагрузки `NOMINATIM_BASE_URL` нужно переключить на собственный
Nominatim/Photon или коммерческий OSM-геокодер. Клиентское приложение менять
не потребуется.

Данные OpenStreetMap распространяются по ODbL. Атрибуция и условия лицензии
должны сохраняться в приложении и пользовательских документах.
