# 1.0.20 (40): управление приёмом заказов

В настройках администратора добавлен переключатель «Заказ такси включён».
Изменения сохраняются отдельно от тарифов и записываются в журнал аудита.
Миграция `049_booking_settings.sql` создаёт выключенную настройку; повторная
миграция не меняет выбор администратора.

При выключенном приёме нажатие кнопки заказа открывает сообщение о наборе
водителей и кнопку «Стать водителем». Проверка происходит до проверки адресов,
на экране подтверждения, в истории поездок и на главной странице сайта.
Недоступность API блокирует продолжение и показывает ошибку соединения.

API проверяет настройку перед созданием и внутри транзакции заказа. Общая
блокировка строки позволяет создавать независимые заказы параллельно и
согласует создание с административным выключением. Повтор запроса уже
созданного заказа сохраняет идемпотентность. Текущие поездки не отменяются.

Проверено: 689 модульных тестов, TypeScript, ESLint, production web export,
37 сценариев API и 13 сценариев конкурентных заказов на отдельной локальной
базе. В браузере проверены сообщение при пустых адресах и переход к анкете.

В выпуск входят ранее подготовленные изменения 1.0.18–1.0.19: ограничение
размеров фотографий, исправления Android 15 и AGP 9.0.1. Подробности в
`android-15-release-1.0.18.md` и `android-build-1.0.19.md`.

Артефакты, журналы сборки и квитанции публикации: `tmp/store-release-1.0.20/`.
Физическое Android-устройство для проверки не использовалось.
