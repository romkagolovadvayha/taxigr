# Загрузка карты в VK Mini Apps — 15 сентября 2026

## Обращение

Модерация VK сообщила о пустой карте на мобильных устройствах при стабильном интернете. На скриншотах видны фон карты, компас и индикатор загрузки, затем сообщение с предложением повторить загрузку. Модель телефона, версия VK и версия встроенного браузера не предоставлены.

## Подтверждённые дефекты

1. Веб-сборка MapLibre 6.9.0 запускала модульный worker. При эмуляции браузера, который игнорирует `WorkerOptions.type`, возникала ошибка `Cannot use import statement outside a module`: управление и фон карты отображались, тайлы не появлялись. Metro не преобразует отдельно загружаемые файлы MapLibre и не добавляет в их worker отсутствующие `Object.hasOwn` и `Array.prototype.at`.
2. Обработчик восстановления ожидал одновременно `sourceDataType: 'content'` и `coord`. В MapLibre 6.9.0 уведомление об успешной загрузке тайла содержит `tile` и `coord`, без `sourceDataType`. После ошибки корректно загруженные тайлы не сбрасывали состояние ошибки. Дополнительно `map.loaded()` ожидал завершения всех источников, включая обновления маршрута.

Эти дефекты воспроизведены на локальном стенде. Без устройства или журналов модерации нельзя утверждать, что именно они были причиной конкретных скриншотов; доступность внешнего сервера карт из сети модератора также не проверена.

## Исправления

- Собираются обычный скрипт и обычный worker с синтаксисом для Chrome 79 / Safari 15. Недостающие встроенные функции добавляются отдельно в обоих окружениях, существующие реализации сохраняются. Требование MapLibre к WebGL2 сохраняется.
- Результаты сборки лежат по новому адресу `/vendor/maplibre/6.9.0/compat-1/`, чтобы браузер не использовал ранее закэшированные файлы. При изменении генератора или совместимости необходимо обновлять `revision` в `maplibre-assets.json`.
- Nginx выдаёт `.cjs` worker с типом `application/javascript`. Публиковать необходимо экспорт вместе с обновлённой конфигурацией nginx; штатный `remote-deploy.sh` устанавливает её и вызывает `nginx -t` перед перезагрузкой.
- Индикатор скрывается после первого отрисованного успешно загруженного тайла подложки. Загрузка метаданных, маршрута или ошибочного тайла не считается готовой картой. Поздний успешный тайл снимает ошибку.
- Сообщение о тайм-ауте больше не утверждает, что проблема вызвана интернет-соединением.

## Проверки

- 33 теста карты, совместимости, загрузчика и ограничений VK прошли.
- `npm run typecheck`, `npm run lint`, `npm run build:web` прошли.
- В браузере при отключённых модульных worker и встроенных `Object.hasOwn` / `Array.prototype.at` исправленная сборка отобразила улицы и подписи Грахово; индикатор завершился. Повторная проверка выполнена с экраном 390 × 844. Это эмуляция ограничений, а не запуск на физическом устройстве с VK.
- Проверка состава релизного архива включает новые скрипты. В дополнительном запуске пяти проверок инструментов публикации одна проверка существующего SFTP/SCP fallback завершилась ошибкой (`test_sftp_failure_recovers_using_scp`: один вызов вместо двух); логика загрузки по SSH в этой задаче не менялась.

## Статус

Исправление и production-экспорт подготовлены локально. Публикация на сервер и повторная отправка на модерацию VK в рамках этой проверки не выполнялись.
