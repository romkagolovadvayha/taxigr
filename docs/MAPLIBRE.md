# Карта MapLibre

Приложение использует `@maplibre/maplibre-react-native` 11 на Android/iOS и
`maplibre-gl` 6 в браузере. Expo SDK 57, новая архитектура React Native.
Для нативной карты нужна новая сборка приложения: Expo Go и прежний APK
без модуля MapLibre не подходят.

## Данные и оформление

Стиль `src/components/map/map-style.ts` поставляется с приложением. В нём есть
светлая и тёмная палитры, дороги, реки, подписи на русском, номера домов,
здания с объёмом при приближении и точки населённых пунктов при отдалении.
Высота здания берётся из данных, при её отсутствии используется условная высота.
Это объёмные здания, а не топографическая модель рельефа всего района.

В браузере источники карты с самого начала свёрнуты в кнопку «Источники карты».
Строка не появляется автоматически, в том числе при загрузке данных или изменении
размера карты. Ссылки открываются только по нажатию на кнопку.

По умолчанию используются тайлы OpenMapTiles от OpenFreeMap и его шрифты Noto Sans.
Геометрия поступает из OpenStreetMap, поэтому детализация зависит от полноты OSM.
Карта не ограничена Граховским районом: межгород остаётся доступен.

Необязательные публичные переменные сборки:

| Переменная | Значение по умолчанию |
| --- | --- |
| `EXPO_PUBLIC_MAP_TILES_URL` | `https://tiles.openfreemap.org/planet` |
| `EXPO_PUBLIC_MAP_GLYPHS_URL` | `https://tiles.openfreemap.org/fonts/{fontstack}/{range}.pbf` |

Первый адрес должен возвращать TileJSON с совместимыми слоями OpenMapTiles.
Собственный сервер должен поддерживать HTTPS и CORS. Атрибуцию OSM нужно сохранять.
Офлайн-пакет района в этой версии не реализован.

## Маршрут и адреса

OSRM продолжает рассчитывать маршрут и стоимость. Карта использует фактическую
геометрию маршрута, показывает промежуточные остановки, автомобиль с направлением,
ETA и оставшуюся часть пути. При маршруте к пассажиру конечный адрес не переносится
на точку подачи. При отсутствии дорожной геометрии вымышленная прямая не рисуется.

В режиме ведения камера смотрит по курсу движения. Жест пользователя временно
останавливает слежение; кнопка «Маршрут» в карточке заказа возвращает его.
Голосовые команды и инструкции по каждому повороту в этой версии отсутствуют.

Поиск, уточнение центра улицы и подпись GPS-точки идут через API приложения.
Координаты выбранной точки сохраняются, даже если геокодер вернул соседний объект.
Для точного центра улицы используется `kind=street`: запрос пропускает приближённые
якоря локального справочника и обращается к кэшируемому Nominatim. Сокращения
«с.», «ул.» и «пер.» нормализуются. Если точного результата нет, пользователь
может выбрать точку на карте самостоятельно.

## Веб-сборка

`app.config.ts` вызывает `scripts/prepare-maplibre-web.cjs`. Скрипт копирует
установленную ESM-библиотеку, worker, общий модуль и CSS в
`public/vendor/maplibre/<version>/`. Файлы автоматически включаются в Expo export;
генерируемый каталог исключён из Git. Библиотека загружается с того же домена,
без стороннего JavaScript CDN. Nginx должен отдавать `.mjs` с MIME
`application/javascript`; конфигурация в репозитории уже настроена.

Не удаляйте vendor-каталоги старых версий сразу при обновлении сайта: у открытой
вкладки ещё может оставаться предыдущий JavaScript. При изменении CSP разрешите
worker с собственного домена и обращения к выбранным источникам тайлов/шрифтов.

## Проверка

```sh
npm run typecheck
npm run lint
npm test
npm run test:integration
npm run build:web
npx expo prebuild --platform android
npx expo run:android
```

Интеграционные тесты запускайте с отдельной MySQL-базой и тестовым API, поскольку
они создают пользователей, заказы и изменяют тарифы.

Проверьте на устройстве: загрузку карты, разрешение геолокации, выбор точки,
поездку с остановками, смену темы, сворачивание/возврат приложения, ручное
перемещение карты и кнопку «Маршрут», отключение/возврат сети. Сборка APK сама
по себе не подтверждает работу GPU и фонового GPS на конкретном телефоне.

Источники: [Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/),
[MapLibre Native для Expo](https://maplibre.org/maplibre-react-native/docs/setup/expo/),
[MapLibre GL JS 6](https://maplibre.org/maplibre-gl-js/docs/guides/v5-to-v6-migration-guide/),
[OpenFreeMap](https://openfreemap.org/quick_start/).
