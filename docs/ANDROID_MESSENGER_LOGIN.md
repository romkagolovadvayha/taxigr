# Открытие мессенджеров при входе на Android

Проверка от 11 сентября 2026 года.

| Способ входа | Реализация | Ограничение |
| --- | --- | --- |
| Telegram | Первый запуск и кнопка повторного открытия используют `appUrl` (`tg://resolve`), с исходным `botUrl` как HTTPS fallback. | Если Telegram отсутствует, открывается веб-ссылка. |
| MAX | Локальный Expo-модуль передаёт исходную ссылку `https://max.ru/<bot>?start=<token>` через `ACTION_VIEW` с `setPackage("ru.oneme.app")`. | Нужна новая Android-сборка. Если MAX отсутствует или не принимает ссылку, используется HTTPS fallback. |
| VK | Android открывает существующее мини-приложение такси в пакете `com.vkontakte.android`, где пользователь подтверждает вход по коду. | Нужны обновлённые API, веб-версия `/vk` и Android-сборка. Если ВК отсутствует, сохраняется Web OAuth 2.1 + PKCE. |

`openExternalAuthChallenge` используется и при первом запуске, и при повторном открытии. Повторное открытие сохраняет ту же попытку входа и её токен. Ошибки запуска приложения больше не показываются как блокировка всплывающих окон браузером.

MAX использует официальный HTTPS-диплинк без преобразования параметров. Android запускает его в указанном пакете без предварительного `canOpenURL`/`queryIntentActivities`; дополнительные разрешения и `<queries>` не нужны. Старые бинарные сборки без нового модуля продолжают использовать HTTPS-ссылку. Web и iOS сохраняют прежнее поведение.

## Прямой вход VK через существующее мини-приложение

Пользовательский `VK_USER_TOKEN` проверен через `account.getAppPermissions` и действует. `apps.get` подтвердил OAuth-приложение `54698895` с типом `standalone`. Поэтому первоначальный вывод о необходимости создания отдельного Android-клиента был преждевременным. ID мини-приложения `54638428` и его ключ уже сохранены в серверной конфигурации.

Реализация использует действующую интеграцию VK Mini Apps с проверкой подписи запуска и подписанного номера телефона. Android SDK VK ID и новые настройки OAuth-клиента для этого сценария не нужны. Пользовательский токен используется только локально для проверки доступа и не включается в приложение.

1. Android передаёт `platform: android` в `/v1/auth/vk/start`.
2. API возвращает обычную OAuth-ссылку и `appUrl` вида `https://vk.com/app<VK_MINI_APP_ID>#native_auth=<state>` с кодом сравнения. Секрет `exchangeToken` остаётся только у инициатора.
3. Android направляет ссылку прямо установленному ВК. При отсутствии ВК или нового нативного метода запускается прежняя OAuth-ссылка.
4. Экран `/vk` выполняет существующую проверку VK-сессии и показывает отдельную кнопку подтверждения с тем же кодом. Само открытие ссылки не подтверждает вход.
5. `/v1/auth/vk/native/confirm` проверяет авторизованную сессию такси, подпись VK, соответствие VK-профиля сессии, номер, блокировку/удаление аккаунта и срок/состояние попытки. Обновление выполняется в транзакции с блокировкой строк.
6. Подтверждение не возвращает токен сессии. Его получает исходное приложение через существующий `/v1/auth/vk/status` с правильным `exchangeToken`, с записью исходных согласий пользователя.

После подтверждения пользователь возвращается в такси; проверка статуса завершает вход. Повторное открытие сохраняет ту же попытку. Отказ — закрыть окно ВК без подтверждения; смена способа входа в такси очищает ожидающую попытку на клиенте.

Миграция БД не требуется. Сначала необходимо развернуть API и веб-версию мини-приложения, затем выпустить Android-сборку. Старые Android-клиенты и браузерный вход сохраняют прежнее поведение. Изменений в кабинете VK ID и нового запроса прав доступа не выполнялось.

## Проверка

- Проверки запуска мессенджеров, Mini Apps, OAuth, подтверждения и получения сессии — 93 теста прошли (9 файлов).
- `npm run typecheck` — успешно.
- ESLint для изменённых TypeScript-файлов — без ошибок.
- `expo export --platform web` — успешно; маршрут `/vk` включён в сборку `tmp/vk-native-login-web`.
- Gradle `:taxigr-external-auth:compileDebugKotlin` — успешно; Expo autolinking обнаружил новый модуль.
- Физического Android-устройства через ADB нет. Проверка реального запуска VK/MAX/Telegram, передачи hash в VK Mini App, подтверждения и возврата в такси ещё нужна на новой сборке.
- Версия приложения не повышалась, развёртывание API/веб-версии и публикация в магазинах в рамках этой проверки не выполнялись.
