# Android 1.0.19 (39): AGP 9

## Изменения

Версия Android Gradle Plugin закреплена на 9.0.1 через
`plugins/with-android-app-optimization.js`. Сохранён Gradle 9.3.1 из Expo SDK 57,
Java 17, React Native 0.86.3 и целевой Android SDK 36. R8 9.0.32 работает в полном режиме,
с оптимизацией кода и ресурсов.

Для SDK 57 используются предусмотренные AGP 9 параметры совместимости:
`android.newDsl=false`, `android.builtInKotlin=false` и
`android.sourceset.disallowProvider=false`. Последний нужен Expo autolinking;
его `preBuild` явно зависит от `generatePackagesList`, поэтому отключение запрета
Directory Provider не теряет зависимость от генерации исходников.

Две небольшие правки Gradle-плагинов применяются через `patch-package` в
`postinstall`, с ошибкой при невозможности применить патч:

- `expo-modules-core+57.0.14.patch`: заменяет удалённый библиотечный
  `defaultConfig.targetSdk` на `lint.targetSdk` и `testOptions.targetSdk`.
- `@react-native+gradle-plugin+0.86.3.patch`: регистрирует общие настройки библиотек
  из модуля приложения один раз, до завершения конфигурации библиотек. Устраняет
  повторную регистрацию `finalizeDsl` после финализации модулей в AGP 9. Также
  сохраняет абсолютный путь для CLI на Windows, если исходники и результат
  находятся на разных дисках: относительный путь между C: и D: невозможен.

Патчи, настройки и `package-lock.json` входят в исходники; изменения не зависят
от локального Gradle-кеша. Успешно проверены откат и повторное применение патчей,
а также конфигурация всех модулей (`gradlew help`). При обновлении Expo / RN
нужно проверить необходимость патчей и удалить их после появления исправлений
в самих зависимостях. Параметры совместимости не рассчитаны на AGP 10.

Локальная сборка использует кеш, временные файлы и промежуточные результаты
в `D:/taxi-build-39/`: диск C: заполнился при первой попытке. Размещение задают
локальные скрипты `tmp/gradle-1.0.19.cjs` и `tmp/build-disk-layout.init.gradle`;
для EAS оно не требуется. Служебная папка корневого Android-проекта остаётся
на C: для совместимости с settings-плагином autolinking.

Итоговый AAB и отчёты проверки сохраняются в `D:/taxi-build-39/release/`:
Windows дополнительно увеличила файл подкачки на C: во время компиляции.
Локальные скрипты проверки и публикации 1.0.19 используют этот каталог.
Журнал самой сборки остаётся в `tmp/store-release-1.0.19/build-google-play.log`.

Проверки типов и ESLint прошли. Повторно прошли 12 тестов обработки фотографий
и аватаров, 28 JVM-проверок системных панелей Android, а также проверка настоящей
функции `cliPath` Gradle-плагина React Native для одного и разных дисков Windows
(`tests/gradle-windows-paths.init.gradle`). Измерения памяти на устройстве
не проводились; подключённых Android-устройств нет.

## Проверка готового AAB

Сборка завершена успешно: 781 задача, из них 755 выполнены. Проверен подписанный
`taxi-grahovo-1.0.19-39-google-play.aab`, 99 302 781 байт, SHA-256
`3ea718c0e6248e2bbf09cf5991767f9bdb8d28ac0a1f9d27904785a8c5b174b5`.

- Встроенные метаданные подтверждают AGP 9.0.1 и R8 9.0.32, полный режим,
  оптимизацию кода и ресурсов.
- `jarsigner` и `bundletool validate` прошли; сертификат совпадает с ключом
  загрузки предыдущих выпусков. Пакет `ru.grahovo.taxi`, версия 1.0.19 (39),
  target SDK 36.
- Проверены production API, нативные модули карты, авторизации и источника
  установки, шрифты, 31 звуковой MP3 и 27 WAV; файлы совпадают с исходниками.
- Включены четыре ABI; все 52 библиотеки arm64/x86_64 имеют выравнивание 16 КБ.
- В итоговом DEX вызовы старых методов цвета системных панелей защищены
  проверками SDK < 35. Отчёт сохраняет полный контекст инструкций после R8.

Отчёты находятся в `D:/taxi-build-39/release/`: `native-verification.json`,
`agp9-verification.json`, `google-play-runtime-verification.json`,
`edge-calls-39.json`. Это проверки сборки; исчезновение рекомендаций Play
не отмечено как подтверждённое.

## Рекомендация об изображениях

См. [расшифровку методов сборки 1.0.18](play-bitmap-audit-1.0.18.md).
Указанные методы принадлежат библиотекам Glide, Fresco, CanHub и AndroidAnimation.
Обработка фотографий уже использует Glide с ограничением размеров, добавленным
в 1.0.18. Этот выпуск не скрывает предупреждения переименованием методов,
исключениями анализатора или удалением нужных декодеров. Отсутствие рекомендации
после публикации должен подтвердить отдельный анализ Google Play.

## Google Play

17 сентября 2026 года в 02:41 UTC подписанный AAB загружен и отправлен на
проверку в production. Отправка заменила ожидавший рассмотрения выпуск 1.0.18.
Повторное чтение API подтвердило 1.0.19 (39) и состояние
`RELEASE_LIFECYCLE_STATE_IN_REVIEW`; доступность обновления пользователям
пока не подтверждена.

SHA-256 загруженного файла совпал с локально проверенным. Описание приложения,
скриншоты и страны распространения проверены после отправки и не изменились.
Квитанция API: `D:/taxi-build-39/release/google.json`.

Удалённый `versionCode` в EAS установлен на 39 и подтверждён повторным
чтением (`eas-version-after.log`), чтобы следующая автоматическая сборка
не повторила уже использованный номер.

Копии основных отчётов и квитанции сохраняются также в
`tmp/store-release-1.0.19/`, рядом с журналом и копией подписанного AAB.
