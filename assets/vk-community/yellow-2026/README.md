## Состав и исходники

- 15 готовых файлов: аватар, две обложки, шесть плиток меню и шесть карточек записей.
- `content.json` — актуальные тексты, идентификаторы и ссылки.
- `application-report.json` — проверенный результат применения и оставшиеся пункты.
- `sources/` — оригиналы созданных иллюстраций; `sources.json` — схема экспорта.
- `manifest.json` — форматы и размеры.

Иллюстрации созданы генератором изображений. Изображения экранов основаны на интерфейсе проекта; поездка, водитель и номер на карточке безопасности — пример. Аватар использует существующий фирменный знак без перерисовки формы.

## Скрипты из корня проекта

```powershell
node scripts/export-vk-yellow-2026.mjs
node scripts/build-vk-yellow-preview.mjs
node scripts/apply-vk-yellow-2026.mjs
```

Последняя команда по умолчанию только выводит план. Изменения через API требуют явного `--apply` и `--part=metadata`, `--part=art`, `--part=posts` или `--part=publish`; `--part=verify` читает состояние. `publish` использован один раз для выпуска новых записей вместо старых с истёкшим сроком редактирования. Журнал выполненных действий хранится в игнорируемой Git папке `tmp/vk-yellow/`; токены читаются из локальных `.env` и `.env.local` и не входят в комплект. Перед повторным запуском публикации используйте сохранённый журнал, чтобы не создавать дубликаты после истечения серверного окна дедупликации.
