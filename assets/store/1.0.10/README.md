# Такси Грахово 1.0.10 — оформление магазинов

Жёлтый фирменный стиль. Шесть рекламных карточек показывают интерфейс в Android-телефоне: заказ, тарифы, вход, водитель, голосовые уведомления и тёмная тема. Лупы увеличивают выбор тарифа и номер машины. Данные поездки на иллюстрациях демонстрационные.

- Скриншоты: JPG, 1080 × 1920, до 554 КБ каждый.
- Google Play feature graphic: PNG, 1024 × 500.
- Иконка для обоих магазинов: PNG, 512 × 512. Сохранена исходная форма логотипа с двумя метками маршрута.
- `sources/` — готовые оригиналы изображений; `sources.json` — соответствие экспортам.
- `manifest.json` — размеры, вес и SHA-256 финальных файлов.

Повторный экспорт: `node scripts/export-store-yellow-2026.mjs`.
Тексты карточек: `store-listing/release-1.0.10.json`.

Материалы подготовлены с помощью генерации изображений по реальным экранам проекта и проверены визуально. Экспорт выполняет только приведение готовых изображений к размерам магазинов.

В декларации Google Play шесть рекламных скриншотов и баннер отмечены как созданные или изменённые с помощью ИИ. Иконка перенесена из существующих материалов бренда.
